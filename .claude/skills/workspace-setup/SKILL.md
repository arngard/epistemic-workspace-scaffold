# 워크스페이스 설치와 갱신

이 스킬은 절차를 로드하는 포인터다. 절차 본체(SSOT(single source of truth; 단일 진실 공급원))는 [AGENTS/epistemic-rules/workspace-setup.md](../../../AGENTS/epistemic-rules/workspace-setup.md).

1. 위 SSOT 문서의 "갱신 흐름"과, 처음 설치면 "처음 설치"를 지금 읽는다. 기억으로 단언하지 않는다.
2. 설치기 명령은 AI가 실행하고, 사용자에게 갱신 내용과 영향 범위를 보인다. 사용자가 설치나 갱신을 지시하지 않았으면 동의를 받는다. 지시나 동의 없이 바꾸는 적용을 하지 않는다.
