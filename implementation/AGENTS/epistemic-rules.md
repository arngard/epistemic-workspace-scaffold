# 구현 폴더 규범

## 로컬 규칙

- 프로젝트 폴더 이름은 가급적 해당 프로젝트의 원격 레포(레포지토리) 이름을 고려하여 짓는다.
- 프로젝트별 기술 스택, 빌드 방법 등의 안내는 각 프로젝트 폴더 안의 문서(해당 프로젝트의 README 등)에 둔다.

코드나 빌드 설정을 만들거나 고칠 때는 [coding-guidelines.md](epistemic-rules/coding-guidelines.md)와 프로젝트 고유 규약 [conventions.md](../../epistemic-structure/architecture/conventions.md), 핵심 제약 [core-constraints.md](../../epistemic-structure/architecture/core-constraints.md)를 읽는다.
