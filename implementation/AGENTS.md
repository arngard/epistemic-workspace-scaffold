# 구현 프로젝트 디스크립터

> 이 워크스페이스에 포함된 구현 프로젝트의 보관 영역. `implementation/` 하위에 프로젝트마다 한 폴더를 만들고 그 폴더에 실제 소스(또는 서브모듈 등)를 둔다. 한 워크스페이스가 여러 프로젝트를 담을 수 있다 (예: Android와 iOS SDK 쌍, 서버와 프런트엔드 쌍).
> "어떤 프로젝트가 존재하는가"의 SSOT(single source of truth; 단일 진실 공급원)는 파일시스템이다 (ref: [AGENTS/epistemic-rules/folder-structure.md](../AGENTS/epistemic-rules/folder-structure.md) "폴더 구조와 디스크립터").
