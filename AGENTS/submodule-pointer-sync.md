# 서브모듈 커밋 포인트 재귀 정합화

본 레포가 다른 레포의 서브모듈일 때, 단위 작업 종료 시점에 상위 레포가 가리키는 pointer를 맞추는 절차. 단위 작업 종료 흐름의 마지막 단계로 조립된다 (cf. [unit-task-workflow.md](unit-task-workflow.md) "종료 흐름").

## 언제 적용되는가

본 레포가 어떤 상위 레포의 서브모듈로 등재돼 있을 때만 적용된다. 독립 레포에는 해당하지 않는다. 이 단계를 빠뜨리면 본 레포의 머지가 끝나도 상위 레포는 옛 커밋을 가리키는 상태로 남아 부정합이 된다.

## 절차

상위 레포에서 서브모듈 pointer를 본 단위 작업 종료 시점의 main HEAD로 갱신한다(`git -C <상위> add <서브모듈> && commit && push`).

상위 레포가 다시 더 상위의 서브모듈이면 같은 절차를 재귀 반복한다. 본인이 변경되면 본인을 가리키는 상위까지 위로 흐르는 단방향 재귀다.

## 검증

정합화 트리의 모든 노드에서 `git submodule status`에 `+` 표시가 없고 `git diff --submodule`이 비어 있어야 한다.
