# 문서 작성 순서

문서를 새로 쓰거나, 범주나 시간성이 바뀔 만큼 고치거나, 폐기할 때의 순서다. 규칙은 각 단계가 가리키는 문서에 있고 이 문서는 순서와 입구만 둔다. 기존 문서의 내용만 고칠 때는 4단계부터 밟는다.

1. 계기 확인: 새 사실, 의견, 예측, 결정, 자료가 계기이면 [ingest-workflow.md](ingest-workflow.md) "표준 시퀀스"를 따르고, 문서를 쓰는 대목에서 이 순서를 쓴다.
2. 기존 문서 찾기: 폴더 디스크립터, `INDEX.md`, 본문 검색으로 같은 주제의 문서를 찾고, 갱신과 신설을 [document-units.md](document-units.md) "1관심사 원칙", "문서 분할 크기", "중복 금지"로 가른다.
3. 범주 정하기: [범주 판별](../../epistemic-structure/AGENTS/epistemic-rules.md) "판별 규칙"을 적용하고 그 범주 묶음의 정의와 작성 스타일을 읽는다. 규범이나 절차를 쓰는 일이면 [norm-authoring.md](norm-authoring.md)를 함께 따른다.
4. 시간성 확인: [document-temporality.md](document-temporality.md)로 날짜 프리픽스 여부를 정한다. 날짜 프리픽스 문서를 고치기 전에는 같은 문서 "날짜 프리픽스의 의미와 종결 신호"로 종결 여부를 확인한다.
5. 쓰기: 문장은 [writing-style.md](writing-style.md), 태그는 [tags.md](tags.md)를 따른다.
6. 구조 반영: 폴더 신설, 이동, 리네임은 [folder-structure.md](folder-structure.md), 동명 문서와 폴더 쌍은 [workspace-and-project-structure.md](workspace-and-project-structure.md) "하위 문서 폴더 규칙", 색인 설명은 [folder-index.md](folder-index.md)를 따르고, 색인을 다시 만든다 (see: [tools.md](tools.md) "색인 생성 스크립트").

폐기는 위 순서 대신 [original-protection-principle.md](original-protection-principle.md)와 [document-temporality.md](document-temporality.md) "시간성 혼합 금지"를 따른다.
