# 세션 시작 요약 확장

자손 레포(레포지토리)가 상류 도구를 고치지 않고 세션 시작 요약([tools.md](tools.md) "세션 시작 요약 스크립트")에 고유 항목(머신 환경 같은 세션 내내 걸리는 사실)을 더하는 자리와 계약이다. 확장을 만들거나 고칠 때 읽는다.

## 자리

- 확장은 레포 루트의 `AGENTS/session-brief/` 바로 아래 `*.py`다. 상류는 이 폴더를 출고하지 않는다.
- 이름이 `_`나 `.`으로 시작하는 항목, `.py`가 아닌 파일, 하위 폴더, 심볼릭 링크는 실행하지 않는다.

## 계약

- 실행: 요약은 확장을 이름 순으로 `python -B <확장> <루트>`로 실행한다. 작업 폴더는 루트이고 표준 입력은 없으며, 환경 변수 `EPISTEMIC_AUDIT_TOOLS`에 상류 도구 폴더를 주고 `PYTHONIOENCODING=utf-8`, `PYTHONDONTWRITEBYTECODE=1`을 둔다.
- 출력: UTF-8로 읽은 표준 출력의 텍스트를 "확장: <파일 이름 줄기>" 절로 판정 절보다 앞에 붙인다.
- 상한: 확장 하나의 출력은 2,000자, 확장 절 합계는 3,000자 안이고, 실행 시간은 확장 하나 30초, 전체 60초 안이다. 합계나 전체 시간을 넘으면 남은 확장은 실행하지 않고 생략 사실만 적는다. 확장이 늘어도 판정 절이 요약 상한 밖으로 밀려나지 않게 하려는 것이다.
- 실패: 종료 코드가 0이 아니거나 제한 시간 안에 끝나지 않으면 출력을 버리고 수집 실패 한 줄을 적는다. 시간 초과 때 확장이 띄운 다른 프로세스는 정리하지 않는다.
- 주의: 확장은 읽기만 하고 `session_brief.py`를 다시 부르지 않는다(재귀를 막는 장치가 없다).
